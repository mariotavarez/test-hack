# Review Diff
> Standard: Claude Code review style

## When To Use
Runs a focused review over the current diff for bugs, regressions, and missing coverage.

## Workflow
- Prioritize correctness, regressions, security risks, and behavior changes.
- Reference files and lines when pointing out a finding.
- Keep summaries short and findings first.
