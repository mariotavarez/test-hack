# Commit Message
> Standard: Conventional Commits

## When To Use
Drafts Conventional Commit messages from staged or working-tree changes.

## Workflow
- Inspect the staged diff and identify the dominant intention of the change.
- Produce a Conventional Commit subject that reflects the why of the change.
- Flag unrelated changes that should be split into a separate commit.
