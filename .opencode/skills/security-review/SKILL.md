# Security Review
> Standard: Security review workflow

## When To Use
Reviews changes for auth, secrets, validation, injection, and dependency risks.

## Workflow
- Prioritize auth boundaries, secret handling, trust boundaries, and data validation.
- Flag unsafe defaults, missing authorization checks, and weak error handling.
- Recommend the smallest practical hardening change first.
