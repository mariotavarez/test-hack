# Playwright E2E
> Standard: Playwright

## When To Use
Creates end-to-end Playwright coverage for primary user journeys and critical regressions.

## Workflow
- Model critical user journeys from entry point to completion.
- Prefer resilient selectors and stable assertions over brittle UI coupling.
- Capture business-rule assertions, not only visibility checks.
