# PR Summary
> Standard: GitHub PRs

## When To Use
Summarizes a branch or diff into a review-ready PR body with risks and test notes.

## Workflow
- Review all commits and changed files included in the branch.
- Draft a concise PR title and a summary focused on why the change exists.
- Call out risks, testing gaps, and rollout notes before marking the PR ready.
