# /test
> Standard: Testing workflow

## Goal
Runs the preferred test workflow and summarizes failures.

## Workflow
- Run the project’s canonical test command for the impacted scope.
- Report failures, skipped coverage, and flaky symptoms only.
- Suggest the next diagnostic step if tests do not isolate the issue.
