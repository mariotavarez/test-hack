# /pr
> Standard: GitHub PRs

## Goal
Drafts or updates a PR title, summary, and review checklist.

## Workflow
- Inspect all commits that will be included in the PR.
- Draft a reviewer-friendly summary with test and risk notes.
- Return a concise PR body ready to paste or submit.
