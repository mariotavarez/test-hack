# /commit
> Standard: Conventional Commits

## Goal
Drafts and optionally executes a Conventional Commit workflow.

## Workflow
- Inspect staged and unstaged changes before proposing a commit.
- Use Conventional Commit semantics with a why-focused subject.
- Avoid empty commits and flag unrelated changes.
